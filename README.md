# Variant Analyzer

A Python-based bioinformatics application for exploring and analyzing genetic variants using real-world ClinVar data from the National Center for Biotechnology Information (NCBI).

## Features

- Load real ClinVar variant data
- Display all variants
- Search variants by Gene Symbol
- Search variants by Allele ID
- Search variants by Clinical Significance
- Clinical Significance statistics
- Variants per Gene statistics
- Dashboard summary
- Export gene reports to CSV
- Bar chart visualization
- Pie chart visualization
- Save charts as PNG images

## Technologies

- Python
- Pandas
- Matplotlib

## Dataset

This project uses publicly available genetic variant data from the ClinVar database provided by the National Center for Biotechnology Information (NCBI).

A reduced dataset was created from the original ClinVar release for demonstration and educational purposes.

Included genes:

- BRCA1
- BRCA2
- TP53
- EGFR
- KRAS
- NRAS
- BRAF
- CFTR
- ALK
- PIK3CA
- PTEN
- APC
- MLH1
- MSH2
- VHL
